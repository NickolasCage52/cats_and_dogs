# КОТОВИНИЛ 2.0

Одностраничная музыкальная студия для фотографий котов и собак. COCO-SSD определяет животное локально, Web Audio API создаёт оригинальную композицию, а IndexedDB хранит пластинку с оптимизированной обложкой и музыкальной конфигурацией.

## Быстрый запуск

Нужен Node.js 20.19+ или 22.12+.

```powershell
npm install
npm run prepare:model
npm run verify:model
npm run dev
```

Откройте адрес Vite, обычно `http://127.0.0.1:5173/`. Уже подготовленная локальная модель находится в `public/models/coco-ssd`; `prepare:model` скачивает её снова только при явном запуске. Сайт при использовании запрашивает веса с собственного домена.

```powershell
npm test -- --run
npm run build
npm run preview
npm run smoke:model -- http://127.0.0.1:4173/models/coco-ssd/model.json
```

`smoke:model` выполняет настоящий инференс локальной модели на тестовом фото кота, собаки и пустом кадре.

## Как работает пластинка

1. Выберите режим «Коты» или «Собаки» и загрузите JPG, PNG или WebP до 10 МБ.
2. Фото декодируется и уменьшается до 1024 px по длинной стороне. COCO-SSD ищет выбранный класс с порогом 0.55. Другой вид животного показывает отдельное состояние с предложением сменить режим.
3. При успехе создаётся альбом с количеством животных, датой, названием, жанром, seed и оптимизированной WebP обложкой до 700 px. Оригинал фото не сохраняется и не отправляется на сервер.
4. Альбом автоматически записывается в IndexedDB. При ошибке хранилища интерфейс честно показывает, что сохранить не удалось, и предлагает повторить.
5. «Слушать винил» запускает AudioContext из пользовательского действия. Жанр, громкость, mute и виниловый шум можно менять. Открытие альбома из коллекции не запускает модель заново.

Первоначальный жанр зависит от горизонтального положения центра распознанного питомца. У котов используются Lo-fi Meow, Cozy Jazz, Cat Funk, Dreamy Ambient, Cozy Waltz; у собак Retro Rock, Disco Paws, Night Blues, Bossa Pets, Synthwave Tails. Для нескольких животных выбранного вида берётся Cat Funk или Disco Paws. Это художественное правило, а не оценка характера животного.

Музыка использует детерминированный `musicSeed`, рассчитанный из байтов снимка, вида и количества животных; он хранится вместе с `genreId` и `musicEngineVersion`. Одинаковая сохранённая пластинка воспроизводит ту же последовательность нот. Источник звука — Web Audio осцилляторы, фильтры, огибающие, бас и перкуссия. Виниловый режим добавляет тихий процедурный surface noise, crackle и редкие pops. В качестве 3D-сцены используется один лениво загружаемый React Three Fiber Canvas; при недоступном WebGL включается CSS-проигрыватель.

Коллекция хранится **только в браузере данного устройства** и может исчезнуть при очистке данных сайта. Синхронизации и аккаунтов нет. Схема IndexedDB имеет версию 1; в версии сайта 1.0 коллекция не существовала, поэтому переносить пользовательские альбомы из неё не требуется.

## Форма обратной связи

Обычный `npm run dev` запускает только Vite: форма покажет, что почта не настроена. Для рабочего endpoint `/api/feedback` нужен Vercel Functions или совместимая среда с серверным `api/feedback.ts`.

1. Создайте проект на Vercel и подключите этот каталог.
2. Подтвердите домен отправителя в Resend, получите серверный API-ключ.
3. Задайте на Vercel переменные `RESEND_API_KEY`, `FEEDBACK_TO_EMAIL`, `FEEDBACK_FROM_EMAIL` по образцу `.env.example`. Значения не должны иметь префикса `VITE_`.
4. После развёртывания проверьте GET `/api/feedback`: `{"available":true}`. Затем отправьте тестовое сообщение через форму и убедитесь, что письмо дошло.

Для локальной проверки формы можно использовать `npx vercel dev` после установки/авторизации Vercel CLI и настройки переменных окружения. Серверная функция проверяет формат, длину и размер запроса, honeypot, origin и частоту отправки в памяти процесса. Последнее ограничение не является распределённой защитой от спама. Ответ «отправлено» выдаётся только после успешного ответа Resend. Фото не передаются в форму.

Без реальных значений переменных и подтверждённого домена почта **не отправляет письма**. Секреты не должны попадать в клиентский bundle или репозиторий.

## Развёртывание

На Vercel установите стандартную сборку Vite: `npm run build`, каталог `dist`. Корневая папка `api` размещает серверную функцию. Сборка содержит `public/models/coco-ssd`; проверьте, что `/models/coco-ssd/model.json` и все shards отдаются с того же домена. На статическом хостинге без serverless распознавание, музыка и коллекция работают, а форма останется недоступной.

## Структура

- `src/features/animal-detection` — классификация двух видов, ленивая загрузка одной модели COCO-SSD и инференс.
- `src/features/vinyl-collection` — альбом, seed, оптимизированная обложка, IndexedDB.
- `src/features/music` — десять жанров и Web Audio секвенсор.
- `src/features/turntable` — 3D-проигрыватель и музыкант.
- `src/features/feedback`, `api/feedback.ts` — клиентская форма и серверная отправка.
- `tests` — логика детекции, состояния, UI, хранилище, музыка и endpoint.

## Ограничения

COCO-SSD может ошибаться на тёмных, размытых и сильно обрезанных снимках. Загрузка модели при первом анализе занимает время. 3D требует WebGL; при его отсутствии доступен 2D-проигрыватель. Аудио требует пользовательского нажатия. Серверная форма требует настройки Resend и деплоя функции.
